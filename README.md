# 🍽️ Restaurant Billing System

A Python-based restaurant ordering and billing system built using
basic Python programming concepts.

## 🚀 Features

- Display restaurant menu
- Add food items to order
- Select quantity
- Calculate item price
- View current order
- Remove items from order
- Calculate total amount
- Find highest-priced item
- Calculate GST
- Generate final bill
- Handle invalid input

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- Exception handling

## 📌 Project Purpose

This project was created to practice Python programming,
problem-solving, and logical thinking by building a
real-world restaurant billing application.

## ▶️ How to Run

1. Download the `.ipynb` file.
2. Open it using Jupyter Notebook or JupyterLab.
3. Run the cells.
4. Follow the menu displayed in the program.
